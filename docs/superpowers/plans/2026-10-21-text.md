# Text (Milestone 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rich text in Mindweave — free text boxes, shape and line labels, per-word bold/italic/underline/strike, font, size, colour and alignment, edited directly on the canvas and styled from the Properties sidebar.

**Architecture:** `mindweave-core` gets a gpui-free rich-text model (paragraphs → styled runs) with every editing operation, grapheme/word navigation, typing-undo grouping, auto-contrast colour and line-label placement, all unit-tested; shapes gain an optional `label` and a built-in `mindweave/text` kind for text boxes (format v3, clipboard v2). `mindweave-desktop` lays text out with gpui's text system (per-run fonts and decorations, wrapping, caching), implements an on-canvas editor on gpui's platform `InputHandler` (caret, selection, IME), and adds the Text tool and a Text section in the Properties sidebar.

**Tech Stack:** Rust 1.95, gpui-kit `=0.8.0` (gpui-pre 0.3.9 text system: `TextRun`, `Font`, `UnderlineStyle`, `StrikethroughStyle`, `shape_text`, `all_font_names()`, `EntityInputHandler`), `unicode-segmentation` (exact pinned version; already in the lockfile).

**Spec:** `docs/superpowers/specs/2026-10-21-text-design.md`

## Global Constraints

- `mindweave-core` stays gpui-free; all text-model logic is unit-tested there. New dependencies pinned `=x.y.z` in `[workspace.dependencies]`; commit `Cargo.lock`.
- Text tool **T** lives in the Home ribbon next to Pointer (V) and Hand (H). Font controls live **only in the Properties sidebar**.
- Double-click empty canvas → new text box; double-click a shape/line → edit its label; double-click a text box → edit it; Enter on one selected text object → edit. Double-click always means text (point editing in milestone 3 uses Cmd+click).
- Styles apply to the selected words; with whole objects selected (not editing) a change sets only that property in every run (per-word other styles kept); unlabeled shapes skipped.
- Default style: app default font family (`None`), size 16 (labels 14), colour `None` = **Auto contrast** (black `#000000` or white `#FFFFFF`, whichever contrasts more with the shape fill / text-box fill / page canvas background), align left (labels centre + vertical middle).
- Font size clamp 1..=1000; size presets `[8, 10, 12, 14, 18, 24, 32, 48, 72]`; wheel/↑↓ step 1.
- Colour palette: 20 preset swatches, last 8 recent colours (stored in app settings), full picker + hex, "Auto".
- Text boxes grow as you type (`auto_width = true`) until a handle is dragged; every handle/Shift/Alt only changes width (re-wrap); font sizes never scale; height always fits content; sidebar H read-only for text boxes; group resize scales text-box position and width only.
- Line/arrow labels follow the line's real angle, rotated 180° when needed so they never read upside-down, with a background patch in the canvas background colour (2-unit padding).
- Shape-label inner padding 8 canvas units; text-box padding 4 units; text boxes have `Style` (default no fill, no stroke, opacity 1).
- Editing session = one document undo step on exit; inside the session, word-grouped typing undo. Empty new text box removed on exit with no undo step; emptied label cleared.
- Format version **3** (v1/v2 load); clipboard payload version **2** (v1 accepted); plain-text paste from another app while not editing creates a text box at the view centre (cap 100,000 characters).
- Missing font family → draw with default font, keep stored name, sidebar marks it missing.
- Performance: ≤ 2 ms layout per keystroke for a 2,000-character box; 500 text boxes pan without frame drops; font list virtualised.

## Review Focus

1. **IME / dead keys / marked text** — composing Japanese or `´`+`e` commits exactly once, cancelling composition leaves no stray text, undo removes the composed word. (Task 5: `ime_compose_commit_and_cancel`.)
2. **Emoji, flags and combining marks** — caret movement, Backspace/Delete and selection never split a grapheme; word moves skip emoji correctly. (Task 1: `graphemes_are_never_split`.)
3. **Leaving edit mode without typing** — Text-tool click then click-away, double-click empty canvas then Escape, undo right after creating: no invisible empty text objects and no undo step left behind. (Task 6: `empty_new_box_leaves_nothing`.)
4. **Hostile/odd files and clipboard** — size 0 / 1e9 / NaN, unknown font names, invalid colours, 1 MB of pasted text: clamped or capped, never panic, never hang. (Task 3: `open_normalises_text_values`, `plain_paste_is_capped`.)
5. **Mixed-style ranges** — toggling bold on a range that is partly bold makes it all bold (second toggle removes), and the sidebar shows "Mixed" for font/size/colour across differing runs. (Task 1: `toggle_on_mixed_range_sets_all_then_clears`.)

### Task 1: Rich-text model and editing operations (core)

**Files:** Create `crates/mindweave-core/src/text.rs`; modify `lib.rs`, root/core `Cargo.toml` (`unicode-segmentation` pinned).

**Interfaces — Produces:**
- `pub struct RunStyle { pub font: Option<String>, pub size: f32, pub bold: bool, pub italic: bool, pub underline: bool, pub strike: bool, pub color: Option<String> }` (serde, `Default` = font None, size 16, rest false/None).
- `pub struct Run { pub text: String, pub style: RunStyle }`; `pub enum HAlign { Left, Center, Right }` (serde lowercase); `pub struct Paragraph { pub runs: Vec<Run>, pub align: HAlign, pub style: RunStyle /* typing style for an empty paragraph */ }`; `pub struct RichText { pub paragraphs: Vec<Paragraph> }` — invariant: at least one paragraph.
- Positions are **byte offsets into `plain()`**, where paragraphs are joined with `'\n'` and a soft line break inside a paragraph is `'\u{2028}'`. All public ops snap positions to grapheme boundaries.
- `impl RichText`: `new(style: RunStyle, align: HAlign) -> Self`, `plain(&self) -> String`, `len(&self) -> usize`, `is_empty(&self) -> bool`, `insert(&mut self, at: usize, text: &str, style: &RunStyle) -> usize` (returns caret after; `'\n'` splits paragraphs, new paragraph inherits align), `delete(&mut self, range: Range<usize>)`, `slice(&self, range: Range<usize>) -> RichText`, `insert_rich(&mut self, at: usize, other: &RichText) -> usize`, `apply(&mut self, range: Range<usize>, change: &StyleChange)`, `apply_all(&mut self, change: &StyleChange)`, `set_align(&mut self, range: Range<usize>, align: HAlign)`, `style_at(&self, at: usize) -> RunStyle` (style typing will use: char before caret, else paragraph style), `summary(&self, range: Range<usize>) -> StyleSummary`, `normalize(&mut self)` (merge identical adjacent runs, drop empty runs, clamp size 1..=1000, drop invalid colours via `normalize_hex_color`), navigation: `prev_grapheme(at)`, `next_grapheme(at)`, `prev_word(at)`, `next_word(at)`, `word_range(at) -> Range<usize>`, `paragraph_range(at) -> Range<usize>`.
- `pub enum StyleChange { Bold(bool), Italic(bool), Underline(bool), Strike(bool), Font(Option<String>), Size(f32), Color(Option<String>) }`.
- `pub enum Mixed<T> { Same(T), Mixed }`; `pub struct StyleSummary { pub font: Mixed<Option<String>>, pub size: Mixed<f32>, pub bold: Mixed<bool>, pub italic: Mixed<bool>, pub underline: Mixed<bool>, pub strike: Mixed<bool>, pub color: Mixed<Option<String>>, pub align: Mixed<HAlign> }`; `impl StyleSummary { pub fn toggle_value(m: &Mixed<bool>) -> bool /* Mixed or false → true; true → false */ }`.
- Constants: `pub const MIN_FONT_SIZE: f32 = 1.0; pub const MAX_FONT_SIZE: f32 = 1000.0; pub const DEFAULT_FONT_SIZE: f32 = 16.0; pub const LABEL_FONT_SIZE: f32 = 14.0;`
